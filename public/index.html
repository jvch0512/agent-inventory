agent-inventory

Inventory of AI systems and agents with EU AI Act classification, an agent risk score and a static review of MCP configurations. Runs in this tab, nothing is uploaded.

Inventory JSON

Fields per system: owner, role (provider, deployer, both), areas (Annex III), practices (Art. 5), usesGpai, interactsWithPeople, generatesContent, deepfake, profiling, autonomy, humanApproval, tools with access, data, logging. See the README.

MCP client configuration (claude_desktop_config.json, .mcp.json)

Static review only: nothing is started or contacted. Secrets are never echoed back in full.
